# TTCD Robustness Pilot

Пилотный проект для проверки пайплайна исследования робастности детектора
временных устройств управления дорожным движением (TTCD) в зонах дорожных работ.

## Цель пилота

Проверить сквозную цепочку: данные → аугментация → обучение → оценка → метрики,
**не подбирая решения по тестовым результатам**.

## Критерии успеха пилота

1. Пайплайн выполняется без ошибок на всех конфигурациях.
2. Визуальная инспекция аугментаций: ≥ 90% применений выглядят реалистично.
3. Метрики на пилотном val согласуются с ручной проверкой (расхождение < 5%).
4. Экстраполированное время основной серии ≤ доступного бюджета.

## Быстрый старт

```bash
# 1. Создание структуры
bash setup.sh
cd ttcd_robustness_pilot

# 2. Создание виртуального окружения
python -m venv .venv
source .venv/bin/activate  # Linux/Mac
# .venv\Scripts\activate   # Windows

# 3. Установка зависимостей
pip install -r requirements.txt

# 4. Размещение данных ROADWork
# См. data/README.md

# 5. Аудит датасета
python scripts/audit_roadwork.py

# 6. Запуск тестов
pytest tests/ -v

# 7. Визуализация аугментаций
python scripts/visualize_augmentations.py --n-samples 50

# 8. Обучение (пилот)
python scripts/train.py --config configs/pilot_baseline.yaml --seed 42
